# Go Back — Beta 6

Go Back Beta 6 is a public beta build for Android device testing.

## What is included

- Home dashboard with today's focus time, task/syllabus progress, and shortcuts to productivity tools.
- Tasks with optional due dates and priorities.
- Local personal notes.
- Focus countdown, stopwatch, and guided Pomodoro sessions.
- Persistent focus timer notification and saved session history.
- Session summaries for today, 7 days, 30 days, and custom date ranges, plus a daily focus goal.
- Weekly focus reminders based on the device's local time.
- Syllabus tracker, exam planner, daily habits, and goals.
- Android screen-time insights and user-defined productive, distracting, and neutral app labels.
- Optional app blocking for selected launchable apps during focus sessions.
- Appearance modes, color palettes, local profile settings, and JSON backup/restore.

## Important beta limitations

- This is a beta release, not a stable production release.
- **YouTube allowed-channel limiting remains disabled and marked as still testing** while reliability issues, including mini-player behavior, are investigated.
- Accessibility-based app blocking can vary by app, Android version, and device manufacturer.
- Usage insights require Usage Access permission; blocking requires the relevant Android accessibility permission.
- Weekly reminders notify the user but do not automatically start a timer or block apps.
- Exported backups are plain JSON and are not encrypted. Keep them private.
- Passing CI does not replace real-device testing.

## Install

Download the APK asset attached to the [GitHub Releases page](https://github.com/kr-ndv/Go-Back/releases). Android may ask you to allow installation from the app used to download the APK.

Back up important data where possible before switching builds. Please report bugs with the device model, Android version, reproduction steps, and screenshots/logs where useful.
